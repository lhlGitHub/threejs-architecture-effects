# Architecture growth starter

Vite + React + Three.js miniature of a Chinese clock tower assembling brick by brick. Scaffolded by the `threejs-architecture-effects` skill.

```sh
npm ci
npm run dev
```

Production check: `npm run build`, then `npm run preview`. Needs Node.js 22.13+ and a WebGL2 browser. No API key.

Drag to orbit, scroll to zoom, use the timeline to scrub construction. Detail cameras jump to the eaves and stone lions.

This design is a working example, not a historical reconstruction. MIT licensed, Copyright (c) 2026 Hailey; Three.js and other npm packages keep their own licenses.
